# Open Source Day 2026

## Overview

These two sessions introduce open source and how modern software is built and shared. Session 1 covers open-source basics and licenses, web fundamentals (HTTP, APIs, REST), and microservices architecture, including how services communicate, store data, and scale. Session 2 covers version control with Git, understanding the architecture of Git and Git commands. It ends with the Git vs GitHub distinction and the fork, commit, push and pull request workflow for contributing to open-source projects.

---

## Session Details

#### **Session 1: Open source and microservices **
* Understanding Open Source Contribution and Licenses(MIT, Apache, GPL)
* HTTP,API and REST basics
* Difference between Monolith and Microservices
* Service communication: REST, gRPC, Kafka, RabbitMQ
* Databases,Caching,load balancing,Docker/Kubernetes
---
#### **Session 2: Version Control Systems & GitHub **

* Basics of Version Control Systems
* Centralized vs Distributed VCS
* Essential Linux commands like: `cd`, `ls`, `pwd`, `mkdir`, `touch`, `cat`
* **Git**: Installation, basic commands: `init`, `status`, `add`, `commit`, `log`
* Branching, merging and advance Git commands: `revert`, `reset`, `rebase`
* **GitHub**: Repository setup, Pull requests and Open source contribution process
