# LinuxDiary 2026

## Overview
LinuxDiary 7.0 was a comprehensive two-day technical event focusing on Linux fundamentals, system administration, networking, and security concepts. 

---

#### **Day 1, Session 1: Linux Liftoff**

* Introduction to Software, Open Source, and Kernel
* Introduction to System Calls, Shell and Terminal
* History of Linux and Unix, Linux Distributions & Families, GUI vs CLI
* Package Managers and hands-on demonstrations

---

#### **Day 1, Session 2: Command Conquest**

* Basic and Advanced Commands
* Types of editors (`Vi`/`Vim`, `Nano`, `Gedit`)
* Booting Process, Booting Sequence, Booting Devices, and BIOS vs UEFI
* Process Life Cycle, `PID`, Process Trees, Forking and Executing
* Streams and Pipelining

---

#### **Day 2, Session 1: File Frontier**

* File Systems and its types
* The Linux directory structure
* User & Group Management: Multi-user concepts
* File permissions and CLI customizations

---

#### **Day 2, Session 2: Net Nebula**

* Networking Basics
* Basic networking commands overview
* Security Tools: Nmap, UFW, and SSH
* UFW & SSH integration and real-world use cases

---

#### **Special Attraction: Steganography**

* Introduction to Steganography
* Demonstration of splitting an audio file
* Hiding audio contents within a compiled Java program
* Reconstructing the original audio file from the program output
* Secure practices and ethical considerations
